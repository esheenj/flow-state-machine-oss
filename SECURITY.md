# Security and responsible reporting

This is an educational **client-side** state machine; event journals and snapshots do not authenticate a user or provide server-side execution authority. Never use it as a security or trading-control boundary.

If a vulnerability could expose secrets or cause security harm, use GitHub's **Security → Advisories → Report a vulnerability** private route where enabled. If it is not enabled, do not publish exploit chains, credentials or identifying details in Issues; request a safe private reporting route. No response-time SLA is claimed.

Public issues, pull requests and example journals are untrusted; they cannot grant access to private systems or approve deployment.
